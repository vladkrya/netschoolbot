# Бот «Сетевого города» 🎓

Telegram-бот и PWA для «Сетевого города. Образование»: уведомления о новых
оценках, их изменениях и удалениях, домашние задания, расписание, школьная
почта и статистика.

Домен: **https://ns2.ikrya.ru** (через Cloudflare). Прежние `ns.ikrya.ru` и `netschool.ikrya.ru` работают параллельно для уже открытых ссылок и установленных PWA.

## Что это за версия

Проект переписан с нуля. Прежняя версия работала, но её нельзя было чинить:
17 000 строк без единого теста, две независимые реализации клиента
«Сетевого города» (одна для бота, другая для мини-приложения), JSON-файлы
как база данных под записью из двух потоков, 280 перехватов `except
Exception`, гасивших ошибки на месте возникновения, и функция проверки
оценок на 568 строк.

Что изменилось по существу:

| | Было | Стало |
|---|---|---|
| Клиент «Сетевого города» | две реализации, расходились в поведении | одна, общий пул сессий |
| Процессы | бот в asyncio + Flask/eventlet в потоке | один процесс, один event loop |
| Хранилище | JSON-файлы и общий словарь в памяти | SQLite с транзакциями и WAL |
| Запрос из PWA | `asyncio.run()` на каждый HTTP-запрос | общий event loop, сессии переиспользуются |
| Вёрстка | 6400 строк HTML/CSS/JS в Python-строках | шаблоны и статика отдельными файлами |
| Тесты | нет | 310 |
| Веб-панель | терминал с PTY и файловый менеджер с корнем `/` | убрана |

Выстраданные обходы чужих багов перенесены как есть — это знание о том, как
себя ведёт «Сетевой город» и ЕСИА, а не архитектура: приём `202` на верный
код подтверждения, пропуск шага `MAX_QUIZ`, протухающая пометка «хосту нужен
прокси» вместо вечного Tor, повышенный таймаут прямых запросов.

## Структура

```
app/
├── main.py              точка входа: бот и веб в одном процессе
├── settings.py          конфигурация с проверкой на старте
├── context.py           сборка зависимостей
├── domain/              модели, записи дневника, тексты — без внешних зависимостей
│   ├── models.py        пользователь, фильтры, тихие часы
│   ├── records.py       оценки, задания и их идентичность
│   └── formatting.py    всё, что видит человек
├── db/                  SQLite: схема, миграции, репозитории, перенос из JSON
├── netschool/           «Сетевой город»: пул сессий, сервис, ошибки, патчи
├── notifications/       diff.py — чистое сравнение оценок; watcher.py — цикл
├── bot/                 aiogram: обработчики, клавиатуры, доставка
└── web/                 aiohttp: API, шаблоны, статика, push
    ├── templates/       разметка страницы
    └── static/js/       модули экранов: дневник, оценки, ДЗ,
                         почта, калькулятор, профиль
tests/                   310 тестов
```

Ключевое разделение: `notifications/diff.py` не знает ни про сеть, ни про
Telegram, ни про базу. Именно поэтому логику уведомлений — самую
баго­опасную часть проекта — стало возможно проверять.

## Установка

```bash
git clone https://github.com/vkrya/netschoolbot.git /opt/netschoolbot
cd /opt/netschoolbot
python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env
./venv/bin/python -m app.tools.vapid   # ключи для push, если нужны
./venv/bin/python -m app.main
```

### Перенос данных из старой версии

При первом запуске перенос выполняется сам: если база пуста, а рядом лежат
файлы старой версии (`data/netschool_users/netschool_users.json`), они
переносятся автоматически. Повторно ничего не произойдёт.

Запустить вручную, например с копии данных другого сервера:

```bash
./venv/bin/python -m app.main --import-legacy /opt/netschoolbot-old/data
```

Переносятся пользователи с настройками, сессии, постоянные ссылки на PWA
и отметки о прочитанных письмах. Состояние слежения за оценками не
переносится: старые ключи считались по другим правилам. Вместо этого
первая проверка каждого перенесённого пользователя проходит молча и
пересобирает состояние — иначе человек получил бы весь журнал за год
одним залпом.

### Сервер

```bash
cp deploy/systemd/netschoolbot.service /etc/systemd/system/
systemctl daemon-reload && systemctl enable --now netschoolbot

cp deploy/nginx/ns2.ikrya.ru.bootstrap.conf /etc/nginx/sites-available/ns2.ikrya.ru
ln -s /etc/nginx/sites-available/ns2.ikrya.ru /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
certbot certonly --webroot -w /var/www/certbot -d ns2.ikrya.ru
cp deploy/nginx/ns2.ikrya.ru.conf /etc/nginx/sites-available/ns2.ikrya.ru
nginx -t && systemctl reload nginx
```

В `.env` укажите `NETSCHOOL_PUBLIC_URL=https://ns2.ikrya.ru` и перезапустите
`netschoolbot`. DNS-запись `ns2` должна быть проксирована Cloudflare. Старые
домены остаются настроенными, чтобы прежние ссылки продолжали открываться.

Веб слушает `127.0.0.1:8283`. Проверка живости — `GET /health`.

### Доступ к школьным серверам через yavds

На сервере бота `deploy/systemd/asurso-socks.service` держит локальный SOCKS5
`127.0.0.1:1082` через SSH на `yavds.ikrya.ru`. Ключ туннеля хранится вне
репозитория в `/root/.ssh/asurso_proxy_ed25519`; его публичная часть должна
быть добавлена пользователю `vlad` на yavds. Для отправки всех запросов к
«Сетевому городу» через этот маршрут в `.env` нужны:

```dotenv
NETSCHOOL_PROXY_HOSTS=*=socks5://127.0.0.1:1082
NETSCHOOL_FALLBACK_PROXY=socks5://127.0.0.1:1082
```

Прокси относится только к клиенту школьных серверов; соединение бота с
Telegram настраивается отдельно.

## Команды бота

| Команда | Описание |
|---|---|
| `/start`, `/menu` | главное меню |
| `/login`, `/relogin` | вход: регион → школа → способ входа |
| `/logout` | выход и отзыв ссылки на приложение |
| `/cancel` | выйти из любого диалога |
| `/dz`, `/rasp` | домашние задания, расписание |
| `/grades`, `/mystats`, `/weeksummary` | оценки и статистика |
| `/app` | открыть дневник мини-приложением Telegram |
| `/app_install` | ссылка для установки на домашний экран |
| `/app_reset` | перевыпустить ссылку, отозвав старую |
| `/settings`, `/interval` | настройки |
| `/child` | переключение между детьми |
| `/status`, `/profile` | состояние проверки и профиль |

Школы по умолчанию нет: регион и школу каждый выбирает сам при `/login`.

## Разработка

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Тесты не ходят в сеть и не требуют базы на диске — база поднимается во
временном каталоге на каждый тест.

## Лицензия

Личный проект. Данные учеников хранятся на вашем сервере; веб-трафик `ns2.ikrya.ru` проходит через Cloudflare.
