Токены и границы доступа

Токен интеграции начинается с nsro_. Срок действия — от 1 до 365 дней, по умолчанию 90. Одновременно у аккаунта может быть до 20 действующих токенов. Название — от 1 до 80 символов.

  1. Создайте отдельный токен для каждого скрипта или сервиса.
  2. Сохраните его сразу: посмотреть тот же токен ещё раз нельзя.
  3. Для замены создайте новый, обновите интеграцию, затем отзовите старый в настройках.

В базе хранится хэш токена. После отзыва или истечения срока новые запросы с ним получают HTTP 401. Потерянный токен заменяется новым. Время последнего использования в настройках обновляется с точностью примерно до пяти минут.

Все токены аккаунта имеют одинаковые права чтения, включая школьную почту. Настройки отдельных разрешений для токена сейчас нет. Разрешены GET и HEAD; HEAD возвращает заголовки без тела, но может запустить ту же загрузку, что GET.

Токен интеграции работает только в /api/v1. Он не заменяет сеанс миниаппа, не позволяет создавать другие токены, менять настройки, переключать ученика, отмечать ДЗ, загружать ответы, отправлять или удалять письма, заказывать справки.

Cookie, Telegram initData, X-Netschool-Token и ?token=… не авторизуют запросы к этому API. Документация и OpenAPI доступны без входа. Токен храните на сервере или в переменной окружения; не добавляйте его в адрес, репозиторий или код публичной страницы.

Данные всегда принадлежат владельцу токена. Выбранный в миниаппе ученик влияет на следующие запросы интеграции. Перед обработкой данных нескольких запусков проверяйте /profile → student_id. Просмотр дневника родными не даёт токену права на чужой аккаунт.

Как читать JSON

Обычный успешный ответ — объект с ok: true и data. Поля кэша необязательны: их отсутствие не означает ошибку. Исключение — скачивание вложения, где успешный ответ содержит файл.

ПолеЗначение
dataОбъект данных конкретного ресурса.
staleЕсли true, данные из устаревшего кэша. Покажите их пользователю с пометкой.
ageВозраст свежего кэша в секундах, когда сервер возвращает это поле.
refreshingЕсли true, загрузка продолжается в фоне. Через некоторое время повторите обычный GET.
reasonПричина ошибки или возврата старых данных. При ok: true данные всё равно можно использовать.

Идентификаторы берите из ответов: ID года, задания, письма и вложения относятся к разным сущностям. Строковые ключи key сравнивайте как строки, не разбирайте их внутренний формат.

Даты — YYYY-MM-DD. Время с суффиксом Z — UTC; с явным смещением — в указанном поясе. Некоторые даты публикации приходят без смещения или пустой строкой: не приписывайте им UTC автоматически. label — текст для интерфейса, для сортировки используйте дату.

Пустой массив — нормальный результат. null, пустая строка и отсутствующее поле могут означать, что школа не предоставила значение. available: false — возможность недоступна этому подключению. Оценка mark — строка: встречаются не только числа. Для вычислений используйте numeric, учитывая null.

Примеры ниже демонстрационные: имена, ID и даты вымышлены, некоторые поля для краткости опущены. Ответы могут содержать дополнительные поля; сохраняйте совместимость с ними.

Дневник и расписание

GET /diary · GET /schedule

Два адреса одного обработчика. week — смещение от текущей недели в часовом поясе пользователя: 0 — текущая, −1 — предыдущая, 1 — следующая. По умолчанию 0. Значения ограничиваются диапазоном −30…30; некорректное число трактуется как 0.

window=current запрашивает выбранную неделю; без него загружается окно из выбранной и двух соседних недель. При использовании ранее сохранённого расширенного кэша компактный запрос также может вернуть более широкое окно — фильтруйте days[].date, если вам нужны ровно семь дней. refresh=1 запрашивает обновление.

{"ok":true,"data":{"week":0,"days":[{
  "date":"2026-11-04","weekday":2,"label":"4 ноября",
  "lessons":[{"number":1,"subject":"Математика","start":"08:30",
    "end":"09:15","time":"08:30–09:15","room":"205","teacher":"Иванова А. А.",
    "topic":"Дроби","absence":"","is_elective":false,"marks":[],"homework":[]}],
  "marks":[],"homework":[]
}]},"stale":false}

weekday: 0 — понедельник, 6 — воскресенье. В уроке есть номер, предмет, начало и конец, кабинет, учитель, тема, отметка посещаемости, признак факультатива. distance_meeting_id, если есть, — идентификатор дистанционного занятия; API не выполняет вход на него.

Оценки и задания есть и внутри уроков, и в массивах дня — не суммируйте оба представления как независимые записи. Дневник может включать расписание, импортированное владельцем в миниаппе. Учитель и время могут отсутствовать.

Объект оценки

subject — предмет; title — название работы; topic — содержание; type — тип работы; date — дата урока; mark — строковая оценка; numeric — числовая оценка или null; weight — вес; lesson_number — номер урока; comment — комментарий; quarter — ключ периода; published_at и marked_at — даты публикации и выставления, если известны.

GET /bells

data.items — расписание звонков школы. Может быть null: тогда используйте время из уроков дневника. Элементы items содержат shift (смена), number (номер урока), start и end (HH:MM), used (используется ли звонок). У этого ресурса кэш свежий в течение суток.

GET /student-class

Возвращает data.name и отображаемое data.label класса. Название может быть пустым, если получить его не удалось.

Домашние задания

GET /homework

Без параметров — задания на текущую и следующие две недели. past=1 — задания за последние четыре недели до вчерашнего дня включительно. Параметры from/to этот маршрут не поддерживает. Для недель за пределами этих окон используйте дневник.

{"ok":true,"data":{"items":[{
  "id":123,"key":"непрозрачный-ключ","subject":"Математика",
  "date":"2026-11-05","type":"Домашняя работа","text":"Решить № 12",
  "attachments":[{"id":456,"name":"Задание.pdf"}],
  "topic":"Дроби","weight":1,"comment":"",
  "published_at":"","observed_at":"","auto_done":false,"classwork":false
}]},"stale":false}

date — срок задания. id используется для получения комментария и ответа. key сопоставляется с отметками выполнения. auto_done означает, что отдельной работы не требуется; classwork — работа в классе. observed_at — когда задание впервые замечено приложением, а не гарантированное время публикации учителем.

GET /homework/done

Возвращает {"keys": [...], "since": ...} внутри data. Задание отмечено владельцем выполненным, если его key входит в keys. since — начало истории этих отметок, если известно. API только читает отметки.

GET /homework/{assignment_id}/comment

Параметр пути — ID задания. Ответ: {"ok":true,"data":{"comment":"Комментарий учителя"}}. Данные запрашиваются без кэша.

GET /homework/{assignment_id}/answer

Сохранённый ответ ученика. В мобильном режиме data содержит available:true и поля text (строка) и files (массив id, name, description); в остальных режимах — {"available":false}. Создание ответа и загрузка файлов через API недоступны.

Оценки, периоды и архив

GET /marks

Главная точка входа для оценок. Без year возвращает текущий учебный год. year — положительный ID из data.years, а не календарный год вроде 2026. Недоступный год не выбирается автоматически.

years — доступные годы; year_id — выбранный ID; year — название года; class_name — класс; archived — архивный год; subjects — предметы; average — средневзвешенная оценка; current_quarter — текущий период; quarters — список периодов с key, label, short, start, end; periods_source — источник периодов; has_totals — наличие итогов; mobile — мобильное подключение.

У предмета есть subject, average, count, marks, lessons, absences, teacher, totals; также может быть attendance. В marks могут присутствовать lesson_topic и уточнённый ключ периода. Счётчики уроков содержат total и done.

Ключи периодов: q1…q4 — четверти, h1…h2 — полугодия, t1…t3 — триместры. Всегда выбирайте ключ из quarters нужного года. Схема и границы могут быть заданы школой или настройками пользователя.

Как загрузить архив

  1. Получите /marks, возьмите ID из years.
  2. Получите /marks?year=ID: в архивном ответе есть итоги и периоды, но массивы текущих оценок предметов изначально пусты.
  3. Для нужного периода вызовите /marks/period?year=ID&quarter=q1, либо загрузите один предмет через /marks/subject.

GET /marks/period

Обязательны year и quarter. Ответ: data.quarter и плоский массив data.marks всех предметов архивного периода.

GET /marks/subject

Обязательны year, quarter, subject. Название предмета берите из /marks. Ответ: data.subject — объект предмета с оценками, посещаемостью, уроками и учителем.

curl --get '{{ base }}/marks/subject' \
  -H 'Authorization: Bearer ВАШ_ТОКЕН' \
  --data-urlencode 'year=123' \
  --data-urlencode 'quarter=q1' \
  --data-urlencode 'subject=Русский язык'

GET /marks/lessons

Обязателен quarter текущего года. Возвращает data.quarter и data.lessons: предмет → total/done. При неполной загрузке школьного периода lessons может быть null — не трактуйте это как ноль уроков.

GET /subject

Обязательны subject и quarter. Аналитика предмета от школы; может содержать средний балл класса и распределение оценок. Только мобильное подключение; при отсутствии данных — available:false.

GET /class-averages

Обязателен quarter. Ответ при наличии данных: {"available":true,"averages":{"Математика":4.2}} внутри data. Только мобильное подключение.

GET /subject/class-history

Обязательны subject и quarter. data.history — накопленные снимки {"at":"2026-11-04T09:00:00Z","value":4.2}, старые сначала. Пустой список означает, что снимков пока нет.

GET /history

История замеченных приложением изменений оценок: до 50 записей за запрос. Для следующей страницы передайте before с ID последней записи предыдущей страницы. Пустой items означает конец истории.

data.items[]: id, kind, subject, date, title, lesson, mark, old, new, seen. seen — время наблюдения в UTC, а не дата урока. История начинается с наблюдения аккаунта приложением и не заменяет архив школьного журнала.

Школьная почта и файлы

GET /mail

folder: Inbox (по умолчанию) или Deleted. page — целое от 1, по умолчанию 1. Размер страницы фиксирован: 50 писем. Другие папки и параметр page_size не поддерживаются.

{"ok":true,"data":{"messages":[{
  "id":7,"subject":"Собрание","author":"Классный руководитель",
  "sent":"2026-11-04T10:00:00","read":false
}],"page":1,"pages":3},"stale":false}

Читайте именно data.messages. Перебирайте page от 1 до pages; при пустой странице остановитесь. Только первая страница Inbox использует общий кэш; остальные страницы и папка Deleted запрашиваются напрямую. Список не содержит полного текста и вложений.

GET /mail/{message_id}

Параметр пути — id из списка писем. Без кэша возвращает id, subject, author, text, sent, read и attachments внутри data. Каждый элемент attachments содержит id и name.

Получение текста автоматически отмечает письмо прочитанным на сервере школы. Даже GET и HEAD могут привести к этой отметке. Не запрашивайте текст каждого письма при фоновом опросе, если нужно сохранить непрочитанные. Отправка, удаление, восстановление и массовая отметка писем API недоступны.

Текст может содержать разметку. При показе на собственной странице экранируйте его или используйте HTML-санитайзер.

GET /mail/recipients

data.items — адресная книга школы. Записи содержат id и name, могут содержать organization и category. ID получателя может быть строкой. Получение справочника не даёт возможности отправлять письма через это API.

GET /attachment/{attachment_id}

Возьмите id из attachments задания, письма или объявления. Для корректного имени передайте name. Ответ — байты файла с Content-Type и Content-Disposition, без JSON-обёртки.

curl --get '{{ base }}/attachment/456' \
  -H 'Authorization: Bearer ВАШ_ТОКЕН' \
  --data-urlencode 'name=Задание.pdf' \
  --fail-with-body --output 'Задание.pdf'

Файл может загружаться до 90 секунд. По таймауту возвращается HTTP 504 с JSON-ошибкой. Проверяйте HTTP-статус перед сохранением ответа как файла. Скачивание использует тот же Bearer-токен; билет миниаппа не нужен.

Другие ресурсы

GET /profile

{"ok":true,"data":{
  "name":"Иван Иванов","school":"Школа № 1","timezone":"Europe/Moscow",
  "student_id":42,"students":[{"id":42,"name":"Иван Иванов","current":true}]
}}

GET /children

data.children — сводка по детям аккаунта. При менее чем двух детях возвращается пустой список. У записи: id, name, current; при успешной загрузке — period, average, count, recent, debts, low и homework с total/left. При сбое одного ребёнка у него появляется error, остальные данные остаются доступны. Проверяйте каждую запись отдельно.

GET /announcements

data.items — школьные объявления: title, text, author, posted, attachments. Файлы скачиваются общим маршрутом вложений.

GET /events

Олимпиады и конкурсы ученика: data.available и data.items. Доступно в мобильном режиме, иначе available=false и пустой items. Событие содержит id, name, description, organization, location, subject, kind, level, status, start, end и files (id, name). Неизвестные школе коды вида, уровня или статуса могут возвращаться без перевода. Школьная загрузка ограничена пятью страницами по 50 событий, поэтому результат не является неограниченным архивом.

GET /references/types

Справочник доступных типов справок: data.available и data.items, при недоступности также возможно message. Зависит от мобильного режима и прав аккаунта школы. Элементы items содержат id и name. Сам заказ справки через API не выполняется.

GET /countdown

data.vacation — текущие или ближайшие каникулы (label, start, end, now), либо null; vacation_exact — точные ли даты. data.exam — экзамен (name, start, confirmed), либо null. Не показывайте приблизительные даты как утверждённые. Кэш — шесть часов.

GET /notes

Свои задачи пользователя. Необязательные from и to — YYYY-MM-DD. По умолчанию от семи дней назад до 60 дней вперёд. Конец не раньше начала; разница не более 400 дней. Некорректная дата заменяется значением по умолчанию. Ответ: data.items; поля задачи: id, date, subject, text, done, time (HH:MM или пустая строка), remind (минут до напоминания или null). Создание и изменение задач недоступны.

GET /search

q обязателен: минимум два символа, обрезается до 100. Поиск нечувствителен к регистру, ё/е; ищет все слова запроса. Возвращает data.homework, data.mail, data.failed, data.pending, data.since.

Задания индексируются с начала учебного года до двух недель вперёд. Почта — до 100 писем, фильтруется с начала учебного года; поиск идёт по теме и автору, без открытия текста. По каждой категории возвращается до 50 совпадений. Это не полнотекстовый поиск по всем письмам.

В pending перечислены ещё загружаемые индексы, в failed — разделы со сбоем (homework или mail). При pending повторите запрос с паузой: пустой результат ещё не окончательный. Индекс заданий обновляется раз в шесть часов, почты — раз в полчаса; refresh=1 этот индекс не сбрасывает.

Кэш и повторные запросы

Обычный GET может вернуть сохранённые данные сразу. Если кэш устарел, сервер запускает обновление, но при долгом ответе школы отдаёт старые данные с stale=true и refreshing=true. При ошибке школы старые данные могут вернуться с reason. Если сохранённых данных нет, запрос ожидает загрузку и может завершиться ошибкой.

На ресурсах с общим кэшем refresh=1 дольше ждёт школу — до 60 секунд, если старый кэш уже есть. Это не гарантия свежего ответа: при долгой загрузке или сбое всё равно возможен stale=true. При первом запросе без кэша эти 60 секунд не являются общим пределом ожидания.

Не все ресурсы используют этот механизм. /profile, /notes, /history, комментарии и текст письма не получают stale/age автоматически. Звонки и каникулы имеют собственные сроки свежести; поиск — отдельные индексы.

Для обычного виджета достаточно опроса раз в несколько минут. Это рекомендация, а не обещанный лимит запросов. Не запускайте refresh=1 в цикле и не загружайте десятки периодов параллельно. Ограничение частоты со стороны школы может прийти как HTTP 503 с reason=rate_limit.

Ошибки и восстановление

{"ok":false,"error":"Передайте действующий токен: Authorization: Bearer <token>","reason":"invalid_token"}
HTTP / reasonДействие интеграции
400 / часто пустой reasonПроверьте параметры по описанию ресурса. Не повторяйте неизменённый запрос в цикле.
401 / invalid_tokenПроверьте Bearer-заголовок, срок и отзыв токена. Создайте новый в настройках при необходимости.
401 / auth или credentialsТокен интеграции может быть исправен, но вход в школу истёк. Владельцу нужно войти заново в боте или приложении.
403 / blockedДоступ аккаунта ограничен администратором.
403 / read_onlyТокен отправлен вне /api/v1. Проверьте базовый адрес.
404 / not_foundПроверьте имя ресурса. Некоторые ошибки роутера могут возвращаться обычным HTTP-ответом без JSON.
405 / read_onlyИспользуйте GET или HEAD. Команды изменения не поддерживаются.
503 / server или rate_limitВременная недоступность или ограничение школы. Повторите с возрастающей паузой.
503 / esia или mfaПроблема Госуслуг или нужно подтверждение входа. Покажите владельцу error.
503 / unknownПокажите описание ошибки; не повторяйте запрос бесконечно.
504 / serverШкола не успела отдать вложение. Повторите скачивание позже.
500Ошибка приложения. Сохраните время, маршрут и HTTP-статус для обращения, исключив токен.

Рекомендуемая задержка после временных сбоев: 5, 15, 30, 60 секунд, затем несколько минут. Добавляйте небольшой случайный сдвиг. На 400, 401 и 403 автоматические повторы без изменения условий обычно не помогают.

Ответ прокси или сетевой сбой может быть HTML или текстом. Сначала проверяйте HTTP-статус и Content-Type, затем разбирайте JSON. Отсутствие доступа к конкретной возможности может быть успешным HTTP 200 с available=false.

Все страницы школьной почты на Python

import json, os
from urllib.parse import urlencode
from urllib.request import Request, urlopen

BASE = "{{ base }}"
TOKEN = os.environ["NETSCHOOL_API_TOKEN"]

def get(path, **params):
    url = BASE + path + ("?" + urlencode(params) if params else "")
    request = Request(url, headers={"Authorization": "Bearer " + TOKEN})
    with urlopen(request, timeout=120) as response:
        payload = json.load(response)
    if not payload.get("ok"):
        raise RuntimeError(payload.get("error", "Ошибка API"))
    return payload["data"]

page = 1
while True:
    data = get("/mail", folder="Inbox", page=page)
    for message in data["messages"]:
        print(message["id"], message["subject"])
    if not data["messages"] or page >= data["pages"]:
        break
    page += 1
# Текст письма запрашивайте только при необходимости:
# message = get("/mail/7")  # школа отметит его прочитанным

Опрос из браузера

Этот API рассчитан на скрипты и серверные интеграции. Разрешающие CORS-заголовки и отдельный OPTIONS для сторонних браузерных приложений не настроены. Для собственного сайта вызывайте API со своего сервера и храните токен там.
