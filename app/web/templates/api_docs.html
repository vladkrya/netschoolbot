1. Создайте токен

Откройте в миниаппе Настройки → API и интеграции. Задайте название и срок действия. Сохраните токен: он показывается один раз.

Каждый токен можно отозвать отдельно. Он открывает собственные данные аккаунта, включая почту. Передавайте его только доверенным приложениям.

2. Выполните запрос

curl '{{ base }}/profile' \
  -H 'Authorization: Bearer ВАШ_ТОКЕН'

Базовый адрес: {{ base }}. Передавайте токен только в заголовке Authorization.

Дневник текущей недели:

curl '{{ base }}/diary?week=0&window=current' \
  -H 'Authorization: Bearer ВАШ_ТОКЕН'

Пример на Python (переменная окружения NETSCHOOL_API_TOKEN):

import json, os
from urllib.request import Request, urlopen

request = Request(
    "{{ base }}/homework",
    headers={"Authorization": "Bearer " + os.environ["NETSCHOOL_API_TOKEN"]},
)
with urlopen(request, timeout=90) as response:
    payload = json.load(response)
print(payload["data"])

3. Обработайте результат

{"ok": true, "data": {…}, "stale": false}

stale=true — данные из устаревшего кэша. refreshing=true — обновление в фоне. age, когда есть, — возраст кэша в секундах. refresh=1 запрашивает обновление у школы.

Ошибка: {"ok": false, "error": "Описание", "reason": "код"}.

400 — параметры; 401 — недействующий токен (invalid_token) или нужен повторный вход в школу; 403 — доступ ограничен; 404 — нет ресурса; 405 — запись запрещена; 503 — школа недоступна; 504 — истёк срок ожидания файла.

Набор данных зависит от школы и режима подключения. При отсутствии возможности некоторые ресурсы возвращают available=false. Повторяйте запросы с паузой; обычный опрос раз в несколько минут достаточен.

Ресурсы

GET /profile — имя, школа, часовой пояс, выбранный ученик и список учеников.

Дневник относится к ученику, выбранному в миниаппе. API не переключает его. /children возвращает сводку по детям аккаунта. Доступ к чужому дневнику через родных сюда не переносится.

Даты — YYYY-MM-DD, время уроков — местное для школы. Значения quarter берите из ответа /marks: они зависят от схемы учебных периодов.
