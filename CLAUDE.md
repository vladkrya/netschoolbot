# Правила для агентов

## Версия приложения

Версия — `__version__` в `app/__init__.py`, её видно внизу меню настроек
миниаппа. Каждый коммит, который меняет поведение бота или миниаппа,
поднимает её в том же коммите:

- **патч** (`5.0.0` → `5.0.1`) — исправление ошибки без новых возможностей;
- **минор** (`5.0.1` → `5.1.0`) — новая возможность, экран, настройка;
  патч при этом обнуляется;
- **мажор** (`5.1.0` → `6.0.0`) — только по просьбе владельца.

Не поднимать за изменения, которых пользователь не увидит: только тесты,
документация, комментарии, CI, скрипты деплоя.

Несколько изменений в одной ветке или PR — одно поднятие по самому крупному
из них. Перед поднятием сверьтесь с `origin/main`: другие сессии могли уже
поднять версию, тогда считайте от неё. Конфликт в этой строке при слиянии
решается взятием большей версии и повторным поднятием от неё.
